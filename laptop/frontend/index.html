laptop → phone → cellular data

Tunnel

          Connection guide
        
        
    
          
  1. 
            
    Turn on your laptop's WiFi hotspot
    
            
    The laptop becomes a tiny access point. The phone will join it as a normal WiFi client, so the carrier sees ordinary phone data — not hotspot data.
    
            
    
              
    Windows: Settings → Network & internet → Mobile hotspot, turn it on.
    
            
    
            
    
              
    nmcli device wifi hotspot ifname wlan0 ssid CellShare password mypass
    
              
    (adjust wlan0 to your WiFi interface name)
    
            
    
          
    2. 
          
  2. 
            
    Connect the phone to that hotspot
    
            
    On the phone, join the hotspot you just created. Keep the screen on, or disable battery optimization for the WiFi so it doesn't drop.
    
          
    3. 
          
  3. 
            
    Start the tunnel on the phone
    
            
    Open the CellTunnel app on the phone. Set a password under Authentication if you want one, then press Start tunnel. The app stays listening on port 12345.
    
          
    4. 
          
  4. 
            
    Find the phone's IP address
    
            
    Phone: Settings → Wi-Fi → tap the connected network → IP address. A Windows hotspot usually assigns 192.168.137.2; a Linux nmcli hotspot uses its own range (check with nmcli connection show).
    
          
    5. 
          
  5. 
            
    Start the tunnel here
    
            
    Enter the phone's address (and password, if set) in the form above and press Start tunnel. This creates the virtual celltun interface on the laptop.
    
          
    6. 
          
  6. 
            
    Apply the network setup
    
            
    Press Apply network setup (needs sudo / admin), or run these manually:
    
            
    
              
    sudo ip addr add 198.18.0.1/32 dev celltun
    
              
    sudo ip route replace default dev celltun
    
              
    sudo sh -c 'echo "nameserver 1.1.1.1" > /etc/resolv.conf'
    
            
    
            
    
              
    netsh interface ipv4 set address name="celltun" static 198.18.0.1 255.255.255.255
    
              
    netsh interface ipv4 add route 0.0.0.0 0.0.0.0 celltun
    
              
    netsh interface ipv4 set dns name="celltun" static 1.1.1.1
    
              
    (run in an elevated terminal)
    
            
    
          
    7. 
          
  7. 
            
    Verify
    
            
    Open a browser and visit ifconfig.me — it should show your cellular IP, not your usual one. All laptop traffic now flows laptop → WiFi → phone → cellular.
    
            
    curl ifconfig.me
    
          
    8. 
          
  8. 
            
    Stopping / undoing
    
            
    Press Stop to tear down the tunnel and Undo to remove the TUN address, default route and DNS override. Then switch the phone off the hotspot.
    
          
    9. 
        

        

          Alternative: phone on your home WiFi
          

            
If the phone is joined to the same home WiFi as the laptop, the same steps work — just use the phone's home-WiFi IP (from its WiFi details) instead of the hotspot IP. The carrier still sees the phone as a plain WiFi client.
